FAQ

ต้องติดตั้ง Web App หรือไม่?

ไม่ต้องติดตั้งโปรแกรม เปิดไฟล์ด้วย Chrome หรือ Edge ได้โดยตรง ข้อมูลเก็บอยู่ใน Browser ที่ใช้เปิด จึงควรดาวน์โหลด Backup เป็นประจำ

PTM Journal ใช้ได้กี่เครื่อง และส่งไฟล์ให้ผู้อื่นได้หรือไม่?

ผู้ซื้อสามารถเก็บและใช้งานบนอุปกรณ์ส่วนตัวของตัวเองได้ แต่ข้อมูลในแต่ละ Browser จะไม่เชื่อมกันโดยอัตโนมัติ สิทธิ์ใช้งานเป็นสิทธิ์รายบุคคล ไม่รวมการคัดลอก แจกจ่าย หรือส่งต่อไฟล์ให้ผู้อื่น โดยสิทธิ์รับอัปเดตและการช่วยเหลือจะอ้างอิงจาก Email ที่ลงทะเบียน

ใช้ร่วมกับไฟล์จาก AI Workflow / PTM Lite ได้หรือไม่?

แนวคิดและคำศัพท์ถูกปรับให้สอดคล้องกัน แต่ Web App ชุดนี้ทำหน้าที่เป็น Trade Journal ด้านกระบวนการและจิตวิทยาโดยเฉพาะ จึงไม่จำเป็นต้องคัดลอกข้อมูลซ้ำลง Workbook

Core Set กับ Guided Set ต่างกันอย่างไร?

Core Set มี eBook, Workbook และ Web App ครบสำหรับฝึกด้วยตัวเอง ส่วน Guided Set ได้รับ Core Set ทั้งหมด พร้อม MyGPT, Audio Book และโปรแกรมฝึก 30 วันในกลุ่ม Facebook แบบปิด

Guided Set ได้รับทุกอย่างพร้อมกันหรือไม่?

Core Set จะส่งภายในวันที่ 3 กันยายน 2569 ส่วน MyGPT, Audio Book และสิทธิ์เข้ากลุ่มจะส่งภายในวันที่ 30 กันยายน จากนั้นเริ่มลงคลิปวันละหนึ่งคลิประหว่างวันที่ 1–30 ตุลาคม

Audio Book และคลิป 30 วันดูย้อนหลังได้หรือไม่?

ดูย้อนหลังได้โดยไม่กำหนดวันหมดอายุในกลุ่ม Facebook แบบปิด ผู้ที่เข้าร่วมภายหลังสามารถเริ่มจากตอนแรกและฝึกตามจังหวะของตัวเองได้ ตราบเท่าที่กลุ่มและแพลตฟอร์มยังเปิดให้บริการ
